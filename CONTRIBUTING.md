# Contributing

AYRN is not yet open for external code contributions. The core architecture (see [`docs/architecture.md`](docs/architecture.md)) is still being defined, and accepting contributions before the agent engine's contracts stabilize would create rework for everyone.

## What you can do now

- **Open an issue** if you spot an inconsistency in the documentation, disagree with an architectural decision, or want to discuss the roadmap. Documentation feedback is welcome immediately.
- **Watch the repo** if you want to be notified when Phase 3 (Core Agent Engine) opens up for contributions — this is the point at which external PRs will start being accepted.

## What contributing will look like once it opens

This section will be filled in before Phase 3 begins, and will cover: local development setup, coding standards, the PR review process, and how architectural decisions get proposed (see `docs/adr/` for the format decisions will be recorded in).
